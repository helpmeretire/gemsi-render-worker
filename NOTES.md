NoJunk Domain Intel — GET/POST /domain?domain=<name or URL> returns RDAP registration (registrar, created, expires, updated, age_days, status, nameservers), DNS (A, AAAA, MX, NS, TXT count, SPF, DMARC, CNAME), an HTTPS probe (reachable, status, server, redirects_to, hsts), risk flags and a 0-100 risk_score.
Price: $0.003 USDC on Base per call (PRICE_ATOMIC 3000) via x402; verify -> gather -> settle; bad input 400 / too large 413 with no payment work.
Upstreams (6s timeout each, parallel): rdap.org bootstrap -> registry RDAP (404 = registered:false; other failure = null registration fields + rdap_unavailable flag), Cloudflare DoH (all queries failing = dns:null + dns_unavailable flag), HEAD/GET https://domain (failure = not_reachable, never fatal). RDAP and DNS both failing -> 502, no settle, no charge.
Env vars: PAY_TO (optional, defaults to Mick's Base wallet), CDP_API_KEY_ID + CDP_API_KEY_SECRET (optional, enables CDP facilitator/Bazaar; otherwise keyless PayAI). No upstream API keys needed.
