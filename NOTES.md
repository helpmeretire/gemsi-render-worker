NoJunk Web Search: GET/POST /search {q (1-400 chars), count 1-10 (default 10), region (optional DDG kl code e.g. us-en), safe moderate|off|strict} returns JSON {query, region, safe, count, results[{rank, title, url, domain, snippet}], source:"DuckDuckGo"|"Bing"|"Yahoo", fetched_at}; redirector links (DDG uddg, Bing ck/a base64 "u", Yahoo RU=) are resolved to the real URL, ads skipped, duplicates removed, entities decoded.
Price: $0.002 USDC on Base per request with at least one result (PRICE_ATOMIC 2000), x402 v2, verify -> search -> settle; PayAI facilitator by default, CDP when CDP_API_KEY_ID/SECRET are set. Unpaid outcomes: 400 bad input, 404 no results (some engine answered cleanly with none), 502 every source failed (error, timeout, bot-challenge page).
Upstream: sources tried in order until one yields results — lite.duckduckgo.com/lite (kl/kp carry region/safe), then www.bing.com/search?count=10&setlang=en&cc=us, then search.yahoo.com/search?n=10 (fallbacks ignore region/safe); browser UA, 8 s timeout each, HTML cached 120 s in caches.default keyed by each upstream URL (count applied after parsing). Scraping is best-effort: a CAPTCHA/"anomaly" page counts as that source failing; if an engine changes its markup, it yields zero results and the next source is used.
Monitoring: GET /health/search (free) runs the fixed query "cloudflare workers" through the same fallback chain and returns only {status ok|degraded|down, result_count, ms, source}; HTTP 503 when not ok. result_count 0 / source null means every engine is blocked or has changed markup.
Env vars: PAY_TO (optional, defaults to Mick's Base wallet), CDP_API_KEY_ID + CDP_API_KEY_SECRET (optional, enables CDP facilitator / Bazaar listing). No other secrets, no search API keys. Tests: test/run.sh (141 checks + Bazaar schema validator, fetch and caches mocked, no network) must print ALL PASS.
