NoJunk LLM: OpenAI-compatible paid API on Cloudflare Workers AI. POST /v1/chat/completions {model?: llama-3.3-70b (default; aliases gpt-4o-mini/default/"") | qwen2.5-coder-32b, messages: [{role: system|user|assistant, content}], max_tokens?: 1-1024 (default 512), temperature?: 0-2 (default 0.7), top_p?, response_format?: {type: json_object}} -> standard chat.completion {id: chatcmpl-<uuid>, object, created, model, choices[0].message, usage}; POST /v1/embeddings {input: string | string[1-32] (each <= 8,000 chars), model?: bge-m3} -> OpenAI embeddings list (1024 dims, usage approx chars/4); GET /v1/models and GET /v1/models/{id} are free. Agents set base_url to <origin>/v1 and attach PAYMENT-SIGNATURE via an x402 client.
Prices (USDC on Base, x402 v2, verify -> model -> settle): chat $0.005 (PRICE "5000"), embeddings $0.001 ("1000"); each route advertises its own 402 requirements and resource URL, a payment signed for the other route is rejected with 402, and all 4xx/5xx are free (no settle).
Upstream: env.AI binding; @cf/meta/llama-3.3-70b-instruct-fp8-fast (OpenAI-style {choices, usage}) and @cf/qwen/qwen2.5-coder-32b-instruct ({response, usage}) are both normalized to one chat.completion object with a fresh id; @cf/baai/bge-m3 ({data: [[1024 floats]...], shape}) is normalized to the OpenAI list. Failure modes, all unpaid: 400 bad input (bad roles, empty messages, stream:true, unknown model, >32,000 chars, max_tokens out of 1-1024, >32 embedding items, empty strings, tools/n>1), 413 body > 160 KB (content-length or body size, checked before any payment work), 502 model throws / empty completion / wrong embedding count (no fallback model: the caller chose it), settle failure -> 402 with empty body, env.AI missing -> 500.
Cost: Workers AI bills Llama 3.3 70B fp8 at about $0.29 per M input tokens and $2.25 per M output tokens, so a maxed-out chat call (~8k tokens in from 32,000 chars + 1,024 out) costs about $0.0046 against the $0.005 price: thin margin on worst-case calls, healthy on typical short ones (a 500-in/200-out call costs ~$0.0006); bge-m3 is about $0.012 per M tokens, so a maxed embeddings call (~64k tokens) costs under $0.001.
Env vars: AI (required Workers AI binding), PAY_TO (optional, defaults to Mick's Base wallet), CDP_API_KEY_ID + CDP_API_KEY_SECRET (optional, enables CDP facilitator / Bazaar listing). No console logging; prompts and completions are never logged or returned on settle failure.
