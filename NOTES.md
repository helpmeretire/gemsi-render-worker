NoJunk QR: two paid routes (POST JSON or GET query) on a zero-dependency Cloudflare Worker. /qr {text 1-1500 chars, format?: svg|png|json (default svg), size?: 128-2048 (default 512), margin?: 0-8 modules (default 4), ecc?: L|M|Q|H (default M), dark?/light?: hex colors} -> svg: body is the SVG document (image/svg+xml, one crisp path), png: real PNG (1-bit palette, stored-deflate zlib, CRC32 + Adler-32), json: {version, ecc, modules, mask, mode, matrix (0/1 strings), svg}; every response carries PAYMENT-RESPONSE, X-QR-Version, X-QR-Modules. /qr/batch {items: [{text, label?}] 1-25, format?: svg|json, same options} -> {count, ecc, format, items: [{label, text, version, modules, svg|matrix}]} with X-QR-Count.
Prices (USDC on Base, x402 v2, verify -> encode -> settle): /qr $0.001 (PRICE "1000"), /qr/batch $0.005 ("5000"); each route advertises its own 402 requirements (qr mimeType image/svg+xml) and a payment signed for the other route is rejected with 402. Free: GET /sample.svg (QR for https://nojunkcrypto.com), GET / info, GET /openapi.json.
Encoder: complete ISO/IEC 18004 implementation inside the Worker (no upstream, no env.AI, no API keys): numeric/alphanumeric/byte (UTF-8) mode selection, versions 1-40 with embedded total-codeword / EC-per-block / block-count tables, Reed-Solomon over GF(256) (0x11D), block interleaving, all 8 masks with the 4 penalty rules, BCH format + version information, finder/alignment/timing patterns and dark module. Verified bit-exact against OpenCV's independent QR encoder across versions 1-39 and all masks (the only differences were remainder bits and OpenCV's own broken 21-L table), and OpenCV decodes the PNGs.
Failure modes, all unpaid (no settle): 400 empty/too-long text, text that does not fit version 40 at the chosen ecc, bad format/size/margin/ecc/color, dark == light, >25 items, PNG size smaller than modules + 2*margin; 413 body or URL > 64 KB (Content-Length check first, then again after reading); 502 if the deterministic encoder ever throws; settle failure -> 402 with empty body. Nothing is ever logged.
Env vars: PAY_TO (optional, defaults to Mick's Base wallet 0x6f76...233f), CDP_API_KEY_ID + CDP_API_KEY_SECRET (optional, enables the CDP facilitator / Bazaar listing; otherwise keyless PayAI). Cost per call: pure CPU, well under 50 ms even for version 40 PNG at 2048 px.
