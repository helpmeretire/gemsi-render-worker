NoJunk Web Search: GET/POST /search {q (1-400 chars), count 1-10 (default 10), region (optional DDG kl code e.g. us-en), safe moderate|off|strict} returns JSON {query, region, safe, count, results[{rank, title, url, domain, snippet}], source:"DuckDuckGo", fetched_at}; redirector links are resolved to the real URL, ads/sponsored rows skipped, duplicates removed, entities decoded.
Price: $0.002 USDC on Base per request with at least one result (PRICE_ATOMIC 2000), x402 v2, verify -> search -> settle; PayAI facilitator by default, CDP when CDP_API_KEY_ID/SECRET are set. Unpaid outcomes: 400 bad input, 404 no results, 502 upstream error/timeout/bot-challenge.
Upstream: https://lite.duckduckgo.com/lite/?q=&kl=&kp= scraped with a browser User-Agent, 8 s timeout, HTML cached 120 s in caches.default keyed by the DDG URL (count is applied after parsing, so it does not split the cache). Scraping DDG lite is best-effort: a CAPTCHA/"anomaly" page is returned as 502 (no charge); if DDG changes its markup, results drop to zero and /health/search (free, fixed query "cloudflare workers", returns only {status, result_count, ms}) shows result_count 0 with HTTP 503 — monitor it.
Env vars: PAY_TO (optional, defaults to Mick's Base wallet), CDP_API_KEY_ID + CDP_API_KEY_SECRET (optional, enables CDP facilitator / Bazaar listing). No other secrets, no search API key.
Tests: test/run.sh builds worker.js, runs test/test.mjs (103 checks, fetch + caches mocked, no network) and the Bazaar JSON-schema validator; must print ALL PASS.
