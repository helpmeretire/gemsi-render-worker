NoJunk Moderate: five paid routes (GET query or POST JSON) on Cloudflare Workers AI. /sentiment {text | texts[1-50]} -> per item {label positive|negative, score, polarity -1..1 (signed score)} + summary counts (DistilBERT SST-2); /safety {text | messages[1-20]} -> {safe, categories[{code S1-S14, name}], raw} (Llama Guard 3 8B; string and {response:{response}} shapes both parsed); /rerank {query, documents[1-100] strings or {id,text}, top_k?} -> results[{rank, id, index, score, text}] best first (BGE reranker); /pii {text, redact?, types?} -> entities[{type, value, start, end}] + redacted "[TYPE]" text; /language {text | texts[1-50]} -> {code ISO 639-1, name, confidence, method}. Free: GET /, /openapi.json, /health (AI binding true/false, no model call).
Prices (USDC on Base, x402 v2, verify -> model -> settle): /sentiment $0.001 ("1000"), /safety $0.002 ("2000"), /rerank $0.002 ("2000"), /pii $0.003 ("3000"), /language $0.001 ("1000"); each route advertises its own 402 requirements and resource URL, and a payment for another route is rejected with 402 (requirements must match AND, since /safety+/rerank and /sentiment+/language share prices, the payload's resource.url path must be this route when present).
Upstream: env.AI binding only. PII: email/phone/ssn/credit_card (Luhn)/ip (v4+v6)/iban (mod-97)/crypto_address (0x, bc1, base58) are regex in the Worker; name/address/date_of_birth/passport use Llama 3.3 70B with a JSON schema only when requested (default types = all); LLM values are only kept when found verbatim in the text, overlapping spans are deduped (longest wins). Language uses Llama 3.3 (first 2,000 chars) with a Unicode-script + Latin-stopword heuristic fallback.
Failure modes, all unpaid (no settle): 400 bad input or any text > 20,000 chars, 413 body > 128 KB (content-length or actual body, before any payment work), 502 sentiment/safety/rerank model throws or returns an unusable result, 502 /pii when only LLM types were requested and the LLM fails; settle failure -> 402 empty body; env.AI missing -> 500 with zero facilitator calls. Paid partial results (documented, deliberate): /pii returns 200 + `llm_error` when the regex pass ran but the LLM step failed (regex entities are real work; `methods.llm` is empty and `types_checked` lists what was actually checked); /language returns 200 with `method:"script"` (or "mixed") + `llm_error` when the LLM fails, never 502.
Env vars: AI (required Workers AI binding), PAY_TO (optional, defaults to Mick's Base wallet 0x6f76...233f), CDP_API_KEY_ID + CDP_API_KEY_SECRET (optional, enables CDP facilitator / Bazaar listing; otherwise keyless PayAI). No console logging; prompts are never returned; cost per call is well under price (DistilBERT/BGE are near-free, Llama Guard ~$0.0003, a 20k-char Llama 3.3 PII call ~$0.002 vs $0.003).
