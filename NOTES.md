NoJunk Document: one paid POST route /convert on Cloudflare Workers AI. Input {url (public http/https, max 20 MB, 20 s timeout, 3 redirects re-checked by the SSRF guard)} or {file_base64 (data: prefix ok), filename?, content_type?}, plus max_chars? (1,000-400,000) -> {name, mime_type, bytes, markdown (capped at max_chars / 400,000 with truncated flag), truncated, total_chars, tokens, word_count (full text), pages_hint ("## Page" headings or form feeds, else null), source_url (null for base64), converted_at}. Type is decided by magic bytes (PDF, PNG, JPEG, WebP, OLE/xls; "PK" zip needs a docx/xlsx/xlsm/xlsb/ods/odt/numbers extension or content_type), then the filename / URL-path extension, then the Content-Type header, then an HTML/XML/SVG text sniff; HTML, plain text, CSV and Markdown are still passed through toMarkdown.
Price $0.01 (PRICE "10000", USDC on Base, x402 v2); flow verify -> fetch (url) -> env.AI.toMarkdown({ name, blob }) -> settle; GET /convert without payment and bad probes return 402 first, bazaar example + schema in the 402 extensions.
Upstream: Workers AI toMarkdown (included with Workers AI; PDF and Office conversion carry no neuron cost for most documents, only image OCR/description bills neurons). It returns {name, mimeType, format, tokens, data}; format "error" -> 422 "could not convert" (no charge); throw / null / no text -> 502 (no charge). pptx is NOT supported by toMarkdown and gets 415.
Failure modes, all unpaid (no settle): 400 bad input / private, loopback, link-local, CGNAT, metadata or dotless url host / bad max_chars; 413 request body > 28 MB (Content-Length and after reading, before any payment work) or file > 20 MB (declared or streamed); 415 unsupported type; 422 converter error; 502 url unreachable, non-2xx, empty, redirect to blocked address or > 3 hops, converter unavailable; settle failure -> 402 with empty body; env.AI (with toMarkdown) missing -> 500. Nothing is ever logged.
Env vars: AI (required Workers AI binding, wrangler [ai] binding = "AI"), PAY_TO (optional, defaults to Mick's Base wallet), CDP_API_KEY_ID + CDP_API_KEY_SECRET (optional, enables CDP facilitator / Bazaar listing; otherwise keyless PayAI).
