NoJunk Chain: x402 paid Cloudflare Worker giving AI agents read-only blockchain lookups (7 EVM chains, Solana, Bitcoin), USDC on Base, no API key, nothing logged.
Routes (GET query or POST JSON): /balance $0.002 {address, chain?} -> native + USDC balance, tx count; /gas $0.001 {chain?} -> gas price, base fee, p25/p50/p75 tips (gwei) or BTC sat/vB; /tx $0.002 {hash, chain (EVM only)} -> tx + receipt, confirmations, decoded ERC-20 transfers; /block $0.001 {chain, number?|hash?} -> block header summary.
Upstreams: publicnode.com JSON-RPC (base-rpc, ethereum-rpc, bsc-rpc, arbitrum-one-rpc, polygon-bor-rpc, optimism-rpc, avalanche-c-chain-rpc, solana-rpc) and mempool.space REST for Bitcoin; 8 s timeout per fetch.
Failure modes: bad input 400 / too large 413 before any payment work; not found 404; node down, timeout, HTML or RPC error 502 (chain=all: only when every chain fails, otherwise 200 with per-chain ok:false) -- none of these settle, so no charge; settle failure returns 402 with empty body.
Env vars (all optional): PAY_TO (Base wallet, defaults to 0x6f76...233f), CDP_API_KEY_ID + CDP_API_KEY_SECRET (Coinbase CDP facilitator, enables Bazaar listing; otherwise keyless PayAI facilitator).
