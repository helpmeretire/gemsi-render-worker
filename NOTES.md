NoJunk Stocks: four GET/POST x402 routes (v2, verify -> fetch -> settle; each route advertises its own requirements and a payment signed for another route is rejected via amount + resource URL). /quote {symbol} $0.001 ("1000") -> price, change, changePercent, previousClose, dayHigh/Low, volume, fiftyTwoWeekHigh/Low, currency, exchange, name, marketState, asOf; /quotes {symbols: comma list or array, 1-20} $0.003 ("3000") -> same fields per symbol fetched in parallel, unknown ones {ok:false, error:"not found"}; /history {symbol, range 1d..max (default 1mo), interval 1m..1mo (default 1d)} $0.002 ("2000") -> candles [{t,o,h,l,c,v,adj}] with null bars dropped + dividends, splits, summary {first,last,changePercent,high,low,avgVolume}, meta; /stats {symbol} $0.002 ("2000") -> from 1y daily bars: returns 1w/1m/3m/6m/1y %, annualized volatility (stdev of daily log returns x sqrt(252)), max drawdown %, SMA20/50/200 + priceAbove, Wilder RSI14, 52-week high/low distance, avgVolume30d. Every response carries `notice` ("informational use only, not investment advice").
Unpaid outcomes: 400 bad symbol (regex ^[A-Z0-9.^=-]{1,12}$), bad range/interval combo (1m only for 1d/5d, other intraday only up to 1mo), >20 symbols, non-object body; 413 body > 16 KB (content-length or actual); 404 Yahoo chart.error / HTTP 404 / empty result / no price / too few bars (final, no fallback host); 502 non-2xx, timeout (8 s per attempt), network error or unreadable JSON on BOTH hosts; settle failure -> 402 with empty body. All checked before any facilitator call for input, and 404/502 never settle.
Upstream: Yahoo Finance chart endpoint https://query1.finance.yahoo.com/v8/finance/chart/{SYMBOL}?range&interval&includePrePost=false&events=div,splits (keyless, unofficial; failure mode is a 429/5xx or format change, which surfaces as 502 and is free for the caller). query2.finance.yahoo.com is tried when query1 fails at the transport/server level. Browser-like UA "Mozilla/5.0 ... NoJunk Stocks/1.0 (+https://nojunkcrypto.com)", Accept application/json. Results cached in caches.default keyed by upstream URL: 15 s for 1m bars (quotes), 60 s other intraday, 300 s daily and longer.
Monitoring: GET /health/data (free, cache bypassed) fetches ^GSPC meta and returns {status ok|down, symbol, price, asOf, ms} (503 when both hosts fail). Free: GET / info, GET /openapi.json (3.1.0, x-guidance, per-route x-payment-info).
Env vars: PAY_TO (optional, defaults to Mick's Base wallet), CDP_API_KEY_ID + CDP_API_KEY_SECRET (optional, CDP facilitator / Bazaar listing); no upstream API keys.
