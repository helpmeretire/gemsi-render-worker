NoJunk Crypto Price — x402 Cloudflare Worker. GET/POST /price?symbol=BTC,ETH (up to 10 tickers from an embedded 270+ symbol table) or ?address=0x..&chain=base|ethereum|bsc|arbitrum|polygon|optimism|avalanche|solana; returns price_usd, market_cap_usd, volume_24h_usd, change_24h_pct, last_updated per coin plus unknown[], source, attribution (Powered by CoinGecko), fetched_at.
Price: $0.001 USDC on Base per successful request (PRICE_ATOMIC "1000"); unknown symbols are free (listed in unknown[]), all-unknown -> 404, bad input -> 400, oversize -> 413, none charged.
Upstream: CoinGecko simple/price and on-chain token API (8s timeout, 30s edge cache via caches.default). Any non-200 (incl. 429 rate limit) or timeout -> 502 with no settle; token not found -> 404 no settle.
Env vars: PAY_TO (optional, defaults to Mick's Base wallet), CG_DEMO_KEY (optional secret; sent as x-cg-demo-api-key — without it simple/price is called keyless and on-chain lookups fall back to the public GeckoTerminal API), CDP_API_KEY_ID / CDP_API_KEY_SECRET (optional; otherwise PayAI facilitator).
Tests: test/run.sh builds worker.js, runs 112 mocked-fetch checks (no network) and the Bazaar JSON-schema validator; prints ALL PASS.
