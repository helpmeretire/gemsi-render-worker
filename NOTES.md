NoJunk Image: two paid POST routes on Cloudflare Workers AI. /generate {prompt 3-1500 chars, steps?: 1-8 (default 4), seed?: integer, format?: png|json} -> format png (default): raw PNG bytes with Content-Type image/png + headers PAYMENT-RESPONSE, X-Image-Bytes, X-Seed (if given), X-Model; format json: {image_base64, content_type, bytes, prompt_chars, steps, seed, model, generated_at}. /describe {image_url (public http/https, image/*, max 10 MB, 15 s timeout, 3 redirects, SSRF guard on every hop) | image_base64 (data: prefix ok), question? (default "Describe this image in detail.", max 500)} -> {description, question, image_bytes, model, generated_at}.
Prices (USDC on Base, x402 v2, verify -> fetch image (describe/url) -> model -> settle): /generate $0.01 (PRICE "10000"), /describe $0.005 ("5000"); each route advertises its own 402 requirements and resource URL (generate mimeType image/png), and a payment signed for the other route is rejected with 402.
Upstream: env.AI binding; generate = @cf/black-forest-labs/flux-1-schnell ({image: base64} -> decoded in 64 KiB chunks, magic bytes sniffed, PNG expected, JPEG served as image/jpeg if that ever comes back); describe = @cf/llava-hf/llava-1.5-7b-hf ({image: [bytes], prompt, max_tokens: 512} -> {description}) with one retry on @cf/unum/uform-gen2-qwen-500m (same input shape). Prompt blocklist (minor term + sexual term, or standalone terms like loli/pedo) -> 400 "prompt not allowed" before any payment work.
Failure modes, all unpaid (no settle): 400 bad input / blocked prompt / private, loopback, link-local, CGNAT, metadata or dotless image_url host; 413 request body > 8 KB (generate) or > 14 MB (describe) checked on Content-Length and again after reading, and image > 10 MB (declared or streamed); 415 image_url not image/* or image_base64 not a recognized image; 502 model throws / unusable output / image_url unreachable, non-2xx, empty, redirect to blocked address or > 3 hops; settle failure -> 402 with empty body; env.AI missing -> 500. Nothing is ever logged.
Cost: Workers AI bills flux-1-schnell per 512x512 tile step, about $0.0003 per default 4-step 1024x1024 image (8 steps ~ $0.0006) against the $0.01 price; llava-1.5-7b is billed per token (~$0.0005 for a 512-token answer) against $0.005. Env vars: AI (required Workers AI binding), PAY_TO (optional, defaults to Mick's Base wallet), CDP_API_KEY_ID + CDP_API_KEY_SECRET (optional, enables CDP facilitator / Bazaar listing).
