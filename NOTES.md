NoJunk Web Read: GET/POST /read {url} fetches one public web page and returns JSON {url, final_url, status, title, description, site_name, published, lang, text, markdown, links[<=50], word_count, truncated, fetched_at}; HTML is converted to clean text/Markdown in-worker (no libs), JSON is pretty-printed, text/XML passed through.
Price: $0.002 USDC on Base per successful read (PRICE_ATOMIC 2000), x402 v2, verify -> fetch -> settle; PayAI facilitator by default, CDP when CDP_API_KEY_ID/SECRET are set.
Upstream: the target page itself (8 s total timeout, <=5 redirects, 3 MB body cap, UA "NoJunk Web Read/1.0 (+https://nojunkcrypto.com)"). Failure modes, all unpaid: 400 bad/private/internal URL, 404 upstream 404/410, 415 non-text content type (PDF/images), 502 other upstream status/timeout/redirect loop/redirect to blocked address.
Limits: SSRF guard blocks localhost, private/link-local/multicast IPv4+IPv6, .internal/.local/.localhost etc. and single-label hosts, but does not resolve DNS (Cloudflare itself refuses Worker fetches to private ranges). JS-only pages return little text.
Env vars: PAY_TO (optional, defaults to Mick's Base wallet), CDP_API_KEY_ID + CDP_API_KEY_SECRET (optional, enables CDP facilitator / Bazaar listing). No other secrets.
