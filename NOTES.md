NoJunk AI Text: three paid POST routes on Cloudflare Workers AI. /summarize {text, style?: paragraph|bullets|tldr, max_sentences?: 1-10, language?} -> {summary, style, input_chars, input_words, model, usage, generated_at}; /extract {text, fields: [names] | {name: description}, instructions?} -> {data: {field: value|null}, confidence, notes, model, usage, generated_at}; /classify {text, labels: [2-20], multi?} -> {label | labels[], confidence, model, usage, generated_at} (labels always validated against the given list).
Prices (USDC on Base, x402 v2, verify -> model -> settle): /summarize $0.005 (PRICE "5000"), /extract $0.005 ("5000"), /classify $0.002 ("2000"); each route advertises its own 402 requirements and resource URL, and a payment signed for another route is rejected with 402.
Upstream: env.AI binding, primary @cf/meta/llama-3.3-70b-instruct-fp8-fast (OpenAI-style response) with one retry on @cf/qwen/qwen2.5-coder-32b-instruct ({response, usage}); both normalized to {text, usage}. Failure modes, all unpaid (no settle): 400 bad input, 413 text > 24,000 chars (checked before any payment work), 502 both models fail / JSON still invalid after one strict retry / classify label not in list after retry and substring match; settle failure -> 402 with empty body; env.AI missing -> 500.
Cost: Workers AI bills the 70B model at about $0.29 per M input tokens and $2.25 per M output tokens, so a worst-case 24,000-character summarize (~6k input tokens, <=400 output tokens) costs under $0.003 against the $0.005 price; classify/extract use max_tokens 60/800; temperature 0.2.
Env vars: AI (required Workers AI binding), PAY_TO (optional, defaults to Mick's Base wallet), CDP_API_KEY_ID + CDP_API_KEY_SECRET (optional, enables CDP facilitator / Bazaar listing). No console logging; prompts are never returned.
