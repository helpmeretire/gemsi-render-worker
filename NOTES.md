NoJunk Speech: three paid POST routes on Cloudflare Workers AI. /transcribe {audio_url | audio_base64 (+content_type?), language?} -> {text, language, language_probability, duration_seconds, word_count, segments:[{start,end,text}], audio_bytes, source, model, generated_at} via @cf/openai/whisper-large-v3-turbo (audio sent as chunked base64, task transcribe, vad_filter); /speak {text <= 400 chars, speaker? (aura-asteria-en default), format?: mp3|json} -> raw audio/mpeg body with PAYMENT-RESPONSE, X-Audio-Bytes, X-Text-Chars headers (or JSON {audio_base64, content_type, bytes, text_chars, speaker, model, generated_at}) via @cf/deepgram/aura-1 (stream, Response, {audio: base64}, ArrayBuffer and Uint8Array results all handled); /translate {text <= 5000 chars, target_lang, source_lang? default en} -> {translated_text, source_lang, target_lang, input_chars, model, generated_at} via @cf/meta/m2m100-1.2b, codes validated against the 100 M2M100 languages, same source/target -> 400.
Prices (USDC on Base, x402 v2, verify -> download/model -> settle -> respond; the MP3 is only sent after settle succeeds): /transcribe $0.02 (PRICE "20000", covers one file up to 20 MB / about 10 minutes), /speak $0.01 ("5000"), /translate $0.002 ("2000"); each route has its own 402 requirements and resource URL, and a payment signed for another route is rejected with 402.
Upstream: env.AI binding (missing -> 500) plus, for audio_url, a direct download with the Web Read SSRF guard (private/loopback/link-local IPs, localhost and internal suffixes rejected with 400 before payment; redirects re-checked, max 3), 20 s AbortController timeout, 20 MB cap, audio/* / video/mp4 / octet-stream only. Unpaid failure modes (no settle): 400 bad input, 413 body > 28 MB (transcribe) / 64 KB (speak, translate) or audio > 20 MB, 415 not audio (bad content-type or an HTML page), 404 audio not found, 502 download error/timeout/too many redirects or model error/unusable result; settle failure -> 402 with empty body.
Cost on Workers AI: Whisper turbo ~$0.0005 per audio minute (10 min = $0.01 against the $0.02 price), Aura-1 ~$0.015 per 1k characters (400 chars = $0.03 worst case against $0.005: keep /speak texts short or raise the price if agents send full-length inputs; typical 100-300 char replies cost $0.0015-$0.0045), M2M100 ~$0.34 per M tokens (5,000 chars ~ 1.5k tokens in+out = ~$0.001 against $0.002).
Env vars: AI (required Workers AI binding), PAY_TO (optional, defaults to Mick's Base wallet), CDP_API_KEY_ID + CDP_API_KEY_SECRET (optional, enables CDP facilitator / Bazaar listing). No console logging; audio bytes and transcripts are never stored.
