NoJunk Geo: three GET/POST routes, each $0.002 USDC on Base (PRICE_ATOMIC "2000", x402 v2, verify -> fetch -> settle; a payment signed for one route is rejected on another via its resource URL). /geocode {q 1-200 chars, limit 1-5 (default 1), country ISO2} -> {query, country, results[{lat, lon, display_name, type, category, importance, address{house_number, road, city (city|town|village|hamlet), county, state, postcode, country, country_code}, bounding_box [s,n,w,e]}], source, attribution, fetched_at}; /reverse {lat, lon, zoom 3-18 (default 18)} -> {lat, lon, zoom, display_name, address, type, category, osm_type, osm_id, ...}; /weather {lat, lon} or {q} -> {query?, place?, lat, lon, timezone, timezone_abbreviation, utc_offset_seconds, local_time, current{temperature_c/f, feels_like_c/f, humidity_pct, precipitation_mm, wind_kph/mph, wind_direction_deg, condition (WMO text), weather_code}, daily[7]{date, condition, weather_code, high_c/f, low_c/f, precipitation_mm, precipitation_probability_pct, sunrise, sunset}, ...}.
Unpaid outcomes: 400 bad input (checked before any facilitator or upstream call), 413 body > 16 KB, 404 no place / "Unable to geocode" / q not found for weather, 502 upstream non-2xx, timeout (6 s), network error or unreadable JSON ("data source temporarily unavailable, no payment taken"); settle failure -> 402 with empty body. Nothing is ever logged.
Nominatim (nominatim.openstreetmap.org, free, usage policy: max 1 request/second, identifying User-Agent, cache results, attribution "Data © OpenStreetMap contributors, ODbL" must be shown by anyone displaying the data): we send UA "NoJunk Geo/1.0 (+https://nojunkcrypto.com; hello@nojunkcrypto.com)", accept-language en, and cache every search/reverse response (including empty ones) in caches.default for 24 h keyed by the upstream URL, so repeated queries never hit them; sustained traffic above ~1 new query/second would violate the policy and risk a block (then a self-hosted Nominatim or a paid geocoder would be needed).
Open-Meteo (api.open-meteo.com, free for non-commercial use, fair-use limit ~10,000 calls/day, attribution "Weather data by Open-Meteo.com (CC BY 4.0)"): forecasts cached 10 min keyed by upstream URL (coordinates rounded to 6 decimals). Since this is a paid service, heavy or commercial volume needs Open-Meteo's paid API plan (customer-api.open-meteo.com with an API key); the free tier is fine for launch-scale traffic.
Monitoring: GET /health/data (free, bypasses cache) geocodes "Sunrise, Florida" and fetches one forecast, returning only {nominatim_status ok|degraded|down, open_meteo_status ok|down, ms} (HTTP 503 when not all ok). Env vars: PAY_TO (optional, defaults to Mick's Base wallet), CDP_API_KEY_ID + CDP_API_KEY_SECRET (optional, CDP facilitator / Bazaar listing); no upstream API keys.
